# VR Audio Guidance System – Navigation in Obscured Environments

A Unity-based VR research prototype exploring how users can navigate and complete tasks using audio cues when visual information is limited.

Developed as part of my Master’s thesis at Technische Universität Ilmenau.

---

## Project Overview

In visually restricted environments such as smoke-filled spaces, darkness, emergency scenarios, or complex training simulations, visual guidance may be unreliable.

This project investigates whether **spatial audio** and **stereo audio** can guide users effectively inside immersive VR environments.

Participants were required to locate sound-emitting targets inside multiple 3D cube-grid layouts using only auditory guidance.

---

## Research Objective

To compare the effectiveness of different audio guidance systems for:

- navigation speed
- sound localization accuracy
- user workload
- overall user experience

---

## Implementation

- Developed in **Unity**
- Built for **VR Headset environments**
- Designed interactive cube-grid task scenarios
- Implemented stereo and spatial audio guidance
- Structured repeatable user test sessions
- Collected participant performance data

---

## Study Scope

- 30 participants tested
- Multiple task orientations
- Within-subject comparison design
- Objective + subjective performance metrics

---

## Key Findings

Spatial audio showed stronger results compared to stereo audio:

- Faster task completion
- Higher sound localization accuracy
- Lower frustration
- Reduced mental workload
- Better immersive guidance experience
